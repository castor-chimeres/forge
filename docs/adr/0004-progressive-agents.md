# ADR-0004 — Progressive agent topology

**Status:** Proposed

## Context
SwarmForge Six-Pack is an inspiration, not a proven optimal architecture for our work.

## Proposal
Start with the minimum useful agent roles; introduce dedicated orchestrator, tester and reviewer only when evaluation shows benefit. Golden Thread remains topology-neutral.

## Validation
Compare quality, cycle time, cost, rework and safety against a smaller baseline.
